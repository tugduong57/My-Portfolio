Featured work

HR, attendance & payroll platform for a restaurant chain

A Hanoi restaurant chain ran attendance on standalone fingerprint/face terminals and payroll on hand-built Excel sheets. I took the project from the first requirements interview to a system that every branch uses daily and that produces the real monthly payroll.

Lead developer & business analyst

Feb 2026 – Present · client project via university lecturers · private codebase
Attendance terminals→ Branch agent (Python)→ Encrypted local buffer→ FastAPI + MySQL→ Timesheet→ Payroll & Excel export

What I did

  • Ran requirement interviews with management, branch managers and accountants; wrote the analysis, use cases and functional spec.
  • Designed the data model around an employment history (job history) so transfers, promotions, rehires and part-time ↔ full-time changes stay correct month by month.
  • Built a Python agent installed at each branch that listens to attendance terminals, buffers punches locally (encrypted) and syncs to the server — packaged as a standalone Windows executable that starts with the machine.
  • Implemented shift scheduling, attendance matching with manager overrides, approval workflows, and a payroll engine (standard workdays per position, allowances/deductions, part-time hour capping, multi-branch pay lines, monthly snapshots).
  • Matched the accountants' existing Excel templates for import/export so the switch-over was painless.
  • Coordinated a small student team, later onboarded junior students for on-site setup; wrote the attendance policy and user guides; trained branch staff.

Engineering choices

  • Nothing is hard-deleted. Soft delete plus an audit log on every change, as the client required.
  • The database is the single source of truth for attendance status — the frontend never re-derives it.
  • Role-based access: management, branch manager, accountant, auditor.
  • Dockerised backend, frontend (Nginx) and MySQL on a Linux VPS, with scripted deploy, backup and restore.
  • AI-assisted development (Claude Code, Gemini) — I own the design, review every change, and test against production backups before deploying.

Outcome

  • Pilot branch live in July 2026, all branches by August 2026.
  • Monthly payroll produced from the system since then, reconciled line by line with the accountants.
