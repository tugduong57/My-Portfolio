Featured work

HR, attendance & payroll platform for a 7-branch restaurant chain

A Hanoi restaurant chain ran attendance on standalone fingerprint/face terminals and payroll on hand-built Excel sheets. I took the project from the first requirements interview to a production system across all 7 branches (300+ employees, ~20 daily users) that produces the real monthly payroll.

Lead Full-stack Developer & Business Analyst

Feb 2026 – Nov 2026 · Outsourced project for a 7-branch restaurant chain · private codebase
7 Hikvision terminals→ Branch agent (Python)→ Encrypted SQLite buffer→ FastAPI + MySQL→ Timesheet & approval→ Payroll & Excel export

What I did

  • Primary developer in a 3-student team for 6 months, then sole developer for the final 4 months, delivering the system from requirements interviews to production across 7 branches (300+ employees, ~20 daily users).
  • Sole owner of all non-coding work: business analysis, system design, DevOps, QA, documentation and user training.
  • Replaced Excel-based workflows with timesheet locking, staff transfer/rehire control and payroll status locking, giving head office a single source of truth.
  • Designed the MySQL data model around employment history so transfers, promotions, rehires and part-time ↔ full-time changes stay accurate month by month; built REST APIs (FastAPI, SQLModel) and a React web app with dashboards, timesheets and approval workflows.
  • Built a Python agent syncing 7 Hikvision terminals via encrypted SQLite, packaged as a standalone executable that starts with each branch machine.
  • Wrote functional specs, attendance policies and user guides, and trained branch managers and accountants.

Engineering choices

  • Nothing is hard-deleted. Soft delete plus an audit log on every change, as the client required.
  • The database is the single source of truth for attendance and payroll status — locking rules prevent unapproved edits and back-and-forth Excel sheets.
  • Role-based access: management, branch manager, accountant, auditor.
  • Deployed with Docker and Nginx on a Linux VPS with scripted deploy, backup and restore.
  • Ensured stability with Pytest and Playwright tests run on production backups; leveraged AI coding agents (Claude Code, Gemini) while owning system design and reviewing every change.

Outcome

  • Live across all 7 branches (300+ employees, ~20 daily active users).
  • Monthly payroll produced from the system and reconciled line by line with the accountants.
